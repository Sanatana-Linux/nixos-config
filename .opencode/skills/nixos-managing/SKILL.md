# NixOS Management

## Quick Decision: What do you need?

| Task | Guidance |
|------|----------|
| Rebuild / activate / rollback | See **Rebuild & Rollback** below |
| Test in a VM | `nixos-rebuild vm --flake .#bhairavi` |

## Rebuild & Rollback

```bash
# Build only (no activation) — the safe default
nixos-rebuild build --flake .#<host>

# VM test (bhairavi only)
nixos-rebuild vm --flake .#bhairavi

# Dry-run activation
nixos-rebuild dry-activate --flake .#<host>

# Activate now + persist boot entry
sudo nixos-rebuild switch --flake .#<host> --impure

# Roll back to previous generation
sudo nixos-rebuild switch --rollback
```

### Option Verification — Always Verify Before Suggesting

Never suggest a NixOS option from memory alone. Options drift between versions. Verify against this repo's pinned nixpkgs:

```bash
# Evaluate an option's existence/value in this flake
nix eval --impure .#nixosConfigurations.<host>.config.<option-path>

# Search options on the web (channel: nixos-unstable)
# https://search.nixos.org/options
```

## Configuration

- **Modules**: `modules/nixos/` and `modules/home-manager/`, enable-by-option pattern. See `nixos-module` skill and `.opencode/rules/nix-module-patterns.md`.
- **Flakes**: `flake.nix` + `flake.lock`. See `nix-flake-ops` skill.
- **New files**: `git add` before building — flakes only see tracked files.

## Secrets

- sops-nix, age-encrypted `external/secrets/secrets.yaml`.
- See `nix-secrets` skill and `.opencode/rules/nix-secrets-management.md`.
- Never commit plaintext secrets.

## Image Building

- **ISO**: `nixos-rebuild build --flake .#chhinamasta` builds the Live USB ISO config.
- The ISO host uses the same flake but with a minimal user (`user`) and no NVIDIA.

## Anti-patterns (stop and reconsider)

- **`nix-env -i`** → installs into a hidden profile, breaks reproducibility. Use `environment.systemPackages` / `home.packages`.
- **Editing `hardware-configuration.nix`** → auto-generated by `nixos-generate-config`. Do not hand-edit filesystem UUIDs.
- **Changing `system.stateVersion`** → controls migration semantics; never bump casually.
- **Overlays in the wrong scope** → with `useGlobalPkgs = true`, home-manager user overlays are ignored. See `nixos-best-practices`.
- **Switching a live host without a successful build** → always `build` first.
- **Not `git add`ing new files** → flakes silently ignore untracked files.
- **Modifying `external/`** → git submodules, managed separately. Do not touch unless explicitly instructed.
- **GC before confirming rollback** → keep the previous generation; don't `nix-collect-garbage -d` right after a rebuild.
